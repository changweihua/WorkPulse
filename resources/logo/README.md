# 记了么 · Logo

品牌名取自「今天记了么？」。三版矢量 Logo，均为纯矢量 SVG 轮廓 + 高清 PNG。

## 文件

| 文件                  | 用途                             |
| --------------------- | -------------------------------- |
| `logo-horizontal.svg` | 横版主标：隶书字标 + 脉搏 + WORKPULSE，用于 README、官网头图 |
| `logo-square.svg`     | 方形图标：深色圆角底 + 白字 + 脉搏，用于头像 / 应用图标备选 |
| `logo-wordmark.svg`   | 纯字版：只有三个隶书字，用于单色 / 小尺寸场景 |

## 设计构成

- **字形**：阿里妈妈刀隶体（OFL 1.1 开源隶书），从字体文件提取「记了么」三个字的原始轮廓转为 SVG path，未修改笔画结构。
- **脉搏波形**：青 → 冰蓝 → 玫红渐变，沿用主程序图标的脉搏语义。
- **四色任务点**：青 / 浅青 / 粉 / 红，对应看板的任务状态色。
- **主色**：灰紫 `#4C4F6E` → 深蓝紫 `#2C2F53`，与主程序图标、启动屏同源。
